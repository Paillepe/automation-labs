# Automatisation – Usine Logicielle

Dépôt du cours (ICSSA Niort, du 24 au 27 novembre 2026), en labs [othila-lab](https://www.npmjs.com/package/@othila-academy/lab).

**Avant le cours : suis [docs/AVANT-LE-COURS.md](docs/AVANT-LE-COURS.md).** Tu installes Docker, VS Code et
l'extension Dev Containers ; tout le reste est dans l'environnement du dépôt.

Une fois l'environnement ouvert :

```bash
usine pull      # télécharge les images des quatre jours (chez toi, pas à l'école)
usine doctor    # vérifie que ton poste est prêt
usine help      # les commandes disponibles
```

Le parcours et les commandes des labs : [docs/LABS.md](docs/LABS.md).
